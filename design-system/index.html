RM Games Design System

Material 3 token model + component catalogue for the Phase 2 shell (docs/09-phase2-shell-plan.md §2A). Chosen direction: A · Chunky Cabinet — outlined shapes on a hard ledge, dark-first with a light variant (switch at the top right). Toggle Dev Mode to inspect a component; Copy as prompt targets Jetpack Compose by default.

Color

M3 roles. Every fill ships its on-* partner, WCAG-checked by math (body ≥ 4.5:1). Values below are read live from the active theme. One interaction family (primary); tertiary is reserved for celebration (“new best”).

Per-game accents — thumbnail fallback fill only (content colour, never interaction):

Typography

M3 type scale (15 styles). Display/headline use the direction's display face; titles, body and labels use the reading face. Scores, timers and ranks use t-num (tabular figures).

Shape

M3 shape scale: none / extra-small / small / medium / large / extra-large / full.

Elevation

A hard “ledge”: a solid offset in --ledge, no blur. Pressed buttons drop to 1px and shift down 3px.

State layers

Hover 8% · focus 10% · pressed 10% · dragged 16% of the content colour; disabled = on-surface at 38% (content) / 12% (container).

Spacing

4dp grid + semantic roles: related (8) < section (24) < major (32); screen gutter 20; touch target ≥ 48.

Motion

M3 standard + emphasized easing; a spring overshoot for score pops and press release; score count-up 900ms.

Icons

Token-driven inline SVG sprite (stroke:currentColor; stroke-width:var(--icon-stroke); rounded caps/joins, 2.25 stroke). Drawn in the style of Lucide / Material Symbols outlined. Never emoji. Full sprite: icons.html.
