# 06 — Out of Scope / Roadmap (Post-MVP)

Explicitly **excluded from MVP**:

1. **Multiplayer / friend groups**: joining a group with friends, each keeping their own score.
2. **Music per minigame**: dedicated soundtrack per game. (App-level music *is* in the MVP since 2026-11-18: one synthesized menu theme + UI sounds, see `02-gameplay-rules.md` "Audio".)

These items go to the post-MVP roadmap and must not block MVP design, but MVP architecture should not make them impossible.
